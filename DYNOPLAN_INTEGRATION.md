1. **Install Dynoplan**:

## Troubleshooting

1. **"Dynoplan executable not found"**:
   - Make sure Dynoplan is built: `cd /home/user_136/dynoplan/build && make`

2. **"No OMPL solution found"**:
   - Run PayloadFourDrones first: `cd build && ./PayloadFourDrones`

3. **Optimization fails**:
   - Check if the state format matches between OMPL and Dynoplan
   - Adjust time limits and cost weights
   - Verify start/goal states are valid

## State Format Compatibility

Your OMPL PayloadFourDrones uses:
- **Payload**: position(3) + quaternion(4) + velocity(3) + angular_velocity(3) = 13
- **Per Drone**: quaternion(4) + angular_velocity(3) + cable_angles(2) + cable_velocities(2) = 11
- **Total**: 13 + 4×11 = 57 states

Dynoplan's payload format may differ - you might need to adjust the conversion in the optimization script.

- **Typical results**: 50% waypoint reduction, gentle motion curves

- **Goal**: Minimize total traversal time
- **Best for**: Emergency missions, time-critical deliveries
- **Settings**: Maximum velocity/acceleration limits
- **Typical results**: 96% waypoint reduction, fastest execution (5.8s)

- **Goal**: Balance all objectives for daily use

- **Typical results**: 50% waypoint reduction, reliable performance

#### 6. **Conservative** - Safety First
- **Goal**: Prioritize safety and reliability over performance
